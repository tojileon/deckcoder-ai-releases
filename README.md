# DeckCoderAI downloads

Official distribution repository for DeckCoderAI, a free, closed-source desktop app for interactive HTML presentations.

This repository contains public release documents and approved app packages attached to GitHub Releases. The application development source is maintained separately in a private repository.

## Mac beta preparation

Version **0.1.0-beta.1**, build **1**, is being prepared. There is no published download yet. A staged draft release is not a public download offer.

The universal Mac app is Developer ID signed as **TOJI LEON**, notarised by Apple and includes its stapled ticket. Runtime validation covers Apple Silicon with macOS 27.0.1. Intel Mac, other macOS versions and physical second-display/projector acceptance remain pending. A public Windows download is not ready.

When a release is published, use the versioned `.zip` asset and its `.sha256` file. GitHub's automatic “Source code” archives contain only these distribution documents; they are not an application download.

## Free use and privacy

Free for personal, educational and commercial use under [the beta licence](LICENSE.txt). External AI tools are separate and may charge their own fees. You retain your rights in your presentations and exports. See the [desktop privacy notice](PRIVACY.txt).

Back up important work and rehearse before presenting. Updates are manual. For beta support, email **hello@remylo.app** with **DeckCoderAI beta** in the subject. Do not send private presentations, passwords or API keys.
