# DeckCoderAI downloads

Official distribution repository for DeckCoderAI, a free, closed-source desktop app for interactive HTML presentations.

This repository contains public release documents and approved app packages attached to GitHub Releases. The application development source is maintained separately in a private repository.

## Mac preview and Windows experiment

Version **0.1.0-beta.1**, build **1**, is available from the [official download page](https://tojileon.com/deckcoderai/download/).

The universal Mac app is Developer ID signed as **TOJI LEON**, notarised by Apple and includes its stapled ticket. Runtime validation covers Apple Silicon with macOS 27.0.1. Intel Mac, other macOS versions and physical second-display/projector acceptance remain pending. A separate [Windows x64 experiment](https://tojileon.com/deckcoderai/download/#windows) is available. It is unsigned and has not been tested on Windows.

Use the versioned `.zip` asset and its `.sha256` file. GitHub's automatic “Source code” archives contain only these distribution documents; they are not an application download.

## Free use and privacy

Free for personal, educational and commercial use under [the beta licence](LICENSE.txt). External AI tools are separate and may charge their own fees. You retain your rights in your presentations and exports. See the [desktop privacy notice](PRIVACY.txt).

Back up important work and rehearse before presenting. Updates are manual. For beta support, email **toji@tojileon.com** with **DeckCoderAI beta** in the subject. Do not send private presentations, passwords or API keys.
